# Door Documentation — NebulaX 2026 PS3

This folder is the development source of truth for the **Door** minitask in PS3 — Train Condition Monitoring.

It is intentionally standalone. Door code, models, configuration, validation, and documentation should not depend on any other PS3 subsystem.
