# SHM Development Documentation

This folder contains the working development specification for the **NebulaX 2026 PS3 Structural Health Monitoring (SHM)** application by **Chache Me If You Can**.

Start with [`00_INDEX.md`](00_INDEX.md), then read the documents in numerical order.

The current official PS3 specification and SHM Info Kit remain authoritative. These project docs translate those requirements into an implementation plan for our repository.
